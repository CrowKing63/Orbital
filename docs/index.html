How it works

Orbital watches your mouse and keyboard globally. No browser extension, no per-app setup — it works everywhere on Windows.

01

Select any text

Mouse drag, double-click, Shift + arrows, Ctrl+A, long-press, or a custom hotkey.

02

The bar appears above your cursor

A floating pill shows up right where you selected — dismiss with Esc, right-click, or a click outside.

03

One click, done

Replace the text in place, copy it to your clipboard, show a popup, or search — no context switching.

Features

Everything runs from the tray. No subscription, no account, no telemetry.

Instant action bar

Select text anywhere on Windows and get a floating pill menu above your cursor.

Any AI provider

OpenAI, OpenRouter, Ollama, LM Studio, or any OpenAI-compatible endpoint — you choose.

Custom prompts

Add, edit, and reorder actions with your own templates using a {text} placeholder.

Local models

Run fully offline with Ollama or LM Studio. No data ever leaves your machine.

Utility actions

Copy, cut, paste, delete, key simulation, and Google Search — no AI calls required.

Private by design

API keys are encrypted with Windows DPAPI and stored locally. Nothing is sent anywhere else.
